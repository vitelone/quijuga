# Mostres HTML de fcf.cat

Desa aquí (des del teu navegador: Ctrl+S → "Pàgina web, només HTML") pàgines reals
per escriure i testejar `fcf_parser.py` sense fer peticions a l'FCF:

1. `jornada.html`: llistat de partits d'una jornada d'una competició de futbol base
2. `acta.html`: fitxa o acta d'un partit
3. `installacio.html`: fitxa d'un camp o instal·lació, si existeix
4. `competicions.html`: índex de competicions o categories

Anota a `urls.txt` la URL original de cada fitxer.
